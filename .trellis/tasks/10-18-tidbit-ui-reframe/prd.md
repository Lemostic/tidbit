# 重构 Tidbit 前沿视觉系统与工作区

## Goal

在不丢失现有交互逻辑的前提下，把 Tidbit 从“通用后台式桌面工具”重构为统一、可辨识的**纸本工作台**：内容像纸，功能像墨，强调编辑感、触感与安静的层级，而不是继续叠加玻璃、卡片与高饱和分组色。

## Background

- 当前主窗口为 500 x 780 的透明无边框 Tauri 窗口，最大化/全屏进入三栏 OneNote 工作区。
- 现有视觉由 `tokens.css`、`globals.css`、`groups.css` 及多层 “polish” 覆盖组成；分组栏、内容卡、玻璃材质和编辑区缺少同一套设计语法。
- 当前工作区有 51 个未提交改动，包含 `src/App.tsx`、`src/features/**`、`src/styles/**`。本次必须基于现状增量修改，不覆盖、不回退用户已有内容。
- 现有交互已有测试覆盖，尤其是晾衣绳、三栏模式、窗口能力、设置持久化、便签隐私与语音备忘录。

## Requirements

### R1. 统一视觉语言

- 采用“纸 + 墨 + 朱砂印记”三层语义：桌面/内容使用暖纸色与细纤维纹理；功能栏使用深墨色；朱砂色仅用于交互焦点、选中与关键动作。
- 不使用紫色渐变、霓虹发光、纯黑背景或通用 SaaS 蓝作为主视觉。
- 新增 `atelier.css` 作为末级视觉层，加载于 `globals.css` 之后，避免破坏现有样式契约与测试。
- 浅色、深色、护眼三套主题必须保持同一品牌语气与可读对比度。

### R2. 主窗口与标题栏

- 标题栏保留窗口拖动、搜索、主题切换、晾衣绳开关、设置、最小化到托盘、最大化、退出。
- 品牌改为编辑感字标；搜索入口与窗口控制保持可发现性。
- 小窗口下不得出现拥挤、重叠或不可点击的控件；420px 以下继续收敛文字标签。

### R3. 分组栏

- 保留“全部”、分组选择、新增分组、编辑分组名称/标记色/背景色、删除确认、拖拽便签到分组。
- 分组栏改为深墨色文件索引样式；当前分组像一张从纸堆中抽出的标签，不再使用斜切几何块。
- 四字以内中文分组名必须可完整显示；超过宽度时省略。

### R4. 便签列表

- 保留便签计数、显示归档、新建、打开、展开/收起、置顶、隐藏内容、归档、云游、晾挂、删除确认、拖拽排序、拖拽到分组。
- 窄窗口使用单列纸卡；宽窗口使用紧凑的索引列表。
- 卡片需清晰区分标题、摘录、时间、字数和状态；操作在 hover/focus 时增强，但键盘仍可访问。
- 隐私便签不得泄露标题或正文。

### R5. OneNote 三栏工作区

- 最大化、全屏或足够宽的自由窗口继续进入三栏布局：左侧分组、中间便签列表、右侧内联编辑器。
- 中间列表必须始终可见，选中便签后右侧显示编辑器；空状态提供新建入口。
- 右侧编辑器应呈现为一张可书写的纸页，而不是套在面板里的通用表单。

### R6. 编辑器

- 保留标题失焦保存、正文 500ms 自动保存、保存状态、分组移动、颜色、富文本工具、语音录制、撤销/重做、删除确认、关闭。
- 编辑区排版应提供清晰的行长、行高与视觉留白；工具条不抢占正文注意力。
- 模态、内联 pane、桌面云游嵌入三种形态共享同一次视觉重构。

### R7. 浮层与桌面形态

- 命令面板、设置、确认框、Toast、恢复向导、锁定页、云游卡片与独立编辑器统一使用纸本/墨色语言。
- 命令面板保留命令/便签标签、键盘上下选择、Enter 执行、Escape 关闭与 180ms 搜索防抖。
- 设置保留所有开关、滑杆、字体、数据目录、锁定密码与备份操作，并可通过内部滚动访问。
- 设置不得继续呈现为窄小的通用表单弹窗；宽窗口/全屏使用约占 1040px 的编辑式设置跨页与侧边索引，窄窗口折叠为单列纸页且无横向溢出。
- 设置必须保持即时保存语义、现有标签与控件语义，并具备清晰的分区层级和至少 10px 的功能性说明文字。

### R8. 晾衣绳

- 保留居中 peek、悬停下拉、移出自动收起、`Esc`/关闭按钮关闭、便签横向拖动与位置持久化、点击打开编辑器、取下便签。
- 晾衣绳不能被左右或上下拖动；卡片只能沿绳水平移动。
- 视觉与新纸本系统一致，但保留绳索、木夹和纸张的触感。

### R9. 液态玻璃

- 保留开关与不透明度设置。
- 玻璃仅用于功能层与临时浮层；便签、编辑纸页等内容层保持不透明纸面，避免文字穿透。
- 不支持的 WebView 继续回退到纯色纸面。

### R10. 可访问性与动效

- 所有操作必须有可见 focus ring、可读 aria-label、键盘可达。
- 动效仅用于层级切换、进入与反馈；支持 `prefers-reduced-motion`。
- 文字对比度与最小字号不低于现有可用水平。

### R11. 交付

- 更新版本号、README 与 CHANGELOG，生成新的 Windows NSIS 与 MSI 安装包。
- 报告安装包绝对路径、大小、SHA256 与验证命令结果。

## Interaction Preservation Contract

以下行为视为锁定契约，不得因视觉重构改变：

- `Ctrl+K` 打开命令面板；`Ctrl+N` 新建便签；`Ctrl+Shift+N` 新建分组；`Ctrl+Shift+B` 备份；`Ctrl+L` 锁定；`Ctrl+,` 打开设置。
- 窗口最大化/全屏在宽度足够时进入三栏模式，中间便签列表不消失。
- 晾衣绳关闭按钮与标题栏开关都可关闭；同一衣架控件在已晾挂时执行“从晾衣绳取下”。
- 云游中的便签不可重复云游、不可挂绳、不可在列表中打开；置顶仍可用。
- 已挂绳的便签不可云游；同一衣架控件可取下。
- 隐藏内容的便签只显示“隐私便签”和加密提示。
- 便签拖拽排序与拖到分组的工作流保持。
- 语音备忘录插入后可在卡片中播放且不触发打开编辑器。
- 设置项、备份、恢复、数据目录迁移与锁定页行为保持。

## Acceptance Criteria

- [ ] 主窗口、三栏工作区、模态编辑器、设置、命令面板、云游卡片和晾衣绳共享同一套纸本/墨色视觉语法。
- [ ] 500 x 780 与 1440 x 960 截图均无明显拥挤、错位、溢出或空白失衡。
- [ ] 三栏模式下始终可见分组、便签列表和编辑区；选择便签后右侧内联编辑。
- [ ] 所有既有交互测试通过，并新增至少一组视觉契约/样式回归测试。
- [ ] `pnpm typecheck`、`pnpm lint`、`pnpm test`、`cargo check` 与相关 Rust 测试通过。
- [ ] Playwright 浏览器审计截图覆盖窄窗、三栏、编辑器与命令面板。
- [ ] 新版本 NSIS/MSI 安装包生成，路径、大小和 SHA256 可核验。

## Out of Scope

- 不新增数据库字段、Rust 业务命令或新的便签功能。
- 不改变云游窗口和晾衣绳的既有几何/持久化协议。
- 不引入在线字体、远程图片或运行时网络依赖。
- 不提交或推送 Git，除非用户后续明确要求。

## Open Questions

无。产品方向由本次“直接调研、设计、开发完成并验证，最后打包”授权决定。
